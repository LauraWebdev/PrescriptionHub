# PrescriptionHub
PrescriptionHub keeps every prescription, reminder, and dose in one simple app, entirely free with no advertisement, data tracking or mandatory account sign-ups.

## Download
Download a nightly developer apk from the releases tab. A Google Play release is pending.

## AI disclosure
**No AI was used for the development of this app.** The app's interface was first prototyped in Figma and the developed with Android Studio by a human. The Github Actions build pipeline was created with self-hosted AI assisted tools. Tests for this application were created with self-hosted AI assisted tools. Any output by any AI assisted tool was manually reviewed and adjusted by a human before it was commited to this repository.
